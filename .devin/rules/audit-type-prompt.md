# Ask which audit type before running

Whenever the user asks to audit a URL, always ask which check they want BEFORE running anything. Present these options:

- R2 Review (Sections 1-10: spelling, dimensions, superlatives, footnotes, trademarks, etc.)
- R3 Review (Sections 11-15: regional content)
- Comparison (requires a second URL)
- Accessibility (WCAG/EAA compliance)
- Broken links check
- All checks

Do not run any audit until the user has told you which check(s) they want.
